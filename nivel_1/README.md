# Ponto de Venda

- **O que o código faz:** 
Este programa simula um PDV (ponto de venda) simples. Ele registra várias compras seguidas, calcula os descontos de cada uma, mostra o valor final e, quando o usuário encerra, exibe um resumo do dia com a quantidade de compras, o total bruto, o total de descontos e o total final.

- **Como ele faz:** 
O código recebe o valor da compra e a idade do cliente. Se a idade for maior ou igual a 65 aplica um desconto de 20%, se após o desconto, o valor ainda for maior que R$100, aplica um desconto extra de 10%. O desconto de 10% é aplicado se o valor excede R$100 independente da idade do cliente. Após isso, armazena as compras em uma lista e exibe o resumo diário.

- **Como rodar:** python pdv.py
